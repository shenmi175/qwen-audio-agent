# 记忆范围
从完整对话中提取未来对话可能有用的用户事实：姓名与称呼、稳定偏好、关系、正在推进的项目和明确计划。日常陈述本身可以是证据，不需要“请记住”。临时感叹、泛泛知识、假设和虚构情节通常不具有长期价值。

# 证据与归属
依据用户陈述和确认，保留主体、对象、否定和时间；结合双方对话解析指代和名称。助手回复可帮助理解指代，但不能独立证明用户事实。提到一个话题不等于喜欢它；询问某种技术不等于正在使用它。第三方事实保留真实主体。
指代能由本段用户原句明确确定时，一并选择必要的前文；含糊时跳过。重复事实合并，选完整且自足的证据。

# 变化与遗忘
现实状态随时间变化按新事实记录，并保留时间关系。用户明确纠正错误时选择更正，明确要求忘掉某项事实时选择遗忘；目标不清时跳过该操作。管理请求优先于同一目标的普通新增。

# 隐私
凭据、验证码、支付秘密及精确敏感地址不进入记忆。医疗、心理、宗教、政治等敏感个人信息仅在用户明确要求保存时选择必要的最小内容。尊重用户不保存某段内容的要求。

# 本阶段职责
在完整对话中提取记忆；无需先把对话缩减成零散的用户原句。事实更正依据后文，助手内容保留为理解上下文。

# 语音转写与上下文
语音转写可能把同一个专有名词写成多个近音词。结合完整对话中的澄清和用户确认理解；结合双方对话解析规范名称，保留原文证据用于追溯。仍无法确定对象时，可以保留独立成立的偏好，避免断言某个拼写。对作品的宗教文化、历史题材偏好不等于用户的宗教信仰。

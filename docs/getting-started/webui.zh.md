# WebUI

WebUI 是浏览器里的对话客户端。Gateway 在自己的源上静态托管它——不需要单独
部署前端服务。

## 打开方式

Gateway 运行中，在另一个终端执行：

```bash
qwenaudio webui
```

命令会打印页面地址（默认 `http://127.0.0.1:3101`）并用默认浏览器打开。
首次使用时浏览器会请求麦克风权限，允许后才能语音对话。

界面默认跟随浏览器首选语言（中文或英文）；如需临时指定，可在地址中添加 `?lang=zh` 或 `?lang=en`。

选项：

| 选项 | 含义 |
| --- | --- |
| `--url URL` | 连接其他地址的 Gateway（默认 `http://127.0.0.1:3101`） |
| `--session ID` | 复用指定的语音会话 |
| `--no-open` | 只打印地址，不打开浏览器 |

在输入框点击“拍照”可打开仅使用相机的预览。拍摄有大小限制的 JPEG 后，可查看、重拍或取消，再选择“加入草稿”；照片作为普通附件保留，点击“发送”才提交，也可从草稿中删除。取消或关闭拍照窗口会释放相机，拍照不会启动麦克风或连续视觉输入。照片附件沿用现有附件处理与保留规则。

## 能做什么

### 完整网页界面与悬浮模式

普通浏览器和手机浏览器都可通过右上角设置齿轮切换悬浮模式和调整外观。悬浮模式支持云朵呼吸球，并复用桌面版的
流光声波球、液态渐变球和状态动画，可用鼠标或触屏拖动；“打开对话”返回完整会话。
切换呈现方式、外观和大小会保留同一个 Gateway Client，不会额外建立模型连接。
完整会话继续提供文字、文件/图片草稿、拍照、新会话、资料库入口和已有任务/权限视图。

设置面板显示当前模型和已配置能力。图片理解、实时视频、后台 Agent 和资料库取决于模型
与服务配置；例如 Qwen Audio 3.1 只支持文字和语音，开启界面不会自动切换模型或配置付费服务。
进入悬浮模式会关闭相机预览；麦克风仍由独立按钮控制。手动断开、30 秒空闲断连和设备配对
沿用同一套实现。悬浮球仅在当前网页内显示，不具有原生桌面或安卓跨应用置顶能力。

可使用 `?ui=orb&lang=zh` 直接进入网页悬浮模式。偏好在浏览器本地保存；`orbSkin` 查询参数
可选择内置皮肤，或选择服务器已通过 `QWEN_AUDIO_WEB_SKINS_DIR` 配置的自定义精灵皮肤。

WebUI 设置中的“断开连接”会停止当前客户端的收音、播放和模型会话；页面及聊天记录保留。
断开后需点击“开始对话”重新连接，刷新当前标签页不会自动恢复已手动关闭的连接。

设置 `QWEN_AUDIO_REALTIME_IDLE_TIMEOUT_SECONDS=30` 后：连接建立后，连续空闲 30 秒自动断开。
用户的有效语音、文字消息、模型回复和播放结束会重新计时；原始静音音频和心跳不会延长时间。
正在说话、生成回复或播放音频时不会自动断开。计时在服务端执行，手机后台节流不影响它。
该配置默认为 `0`（关闭）；修改后重启 Gateway。它与保留 Realtime 连接的桌面休眠独立。

- **全双工语音**——自然说话、随时打断，实时转写同步显示。
- **文本与附件**——输入文字、添加图片或文件；普通附件可交后台处理，不要求语音模型直接看图。
- **任务视图**——跟随派发给后台 Agent 的后台任务，包括进度与最终结果。

支持视频输入时，设置中会增加“开启视频”按钮，点击打开摄像头小窗；麦克风仍由原来的按钮独立控制。关闭视频不影响语音。步骤见[视觉输入](../guides/vision.zh.md)。普通附件的处理方式见[对话与附件](../guides/conversation.zh.md)。
设置中的“资料库”入口用于[导入本机文档](../guides/knowledge.zh.md)，不是聊天附件上传。

## 与其他客户端的关系

TUI、WebUI、桌面悬浮球都使用同一套 Gateway Client Protocol。一个 Gateway
对每个用户只接受**一个活动 Client 连接**；另一客户端可在确认后接管，旧连接会断开。
桌面版也可以运行自己的 Gateway 进程，并与 CLI 共享用户配置。桌面版的对话窗口
复用同一套 WebUI 页面，因此各端的展示行为保持一致。

## 从远程浏览器访问

使用[远程连接](../operations/remote-access.zh.md)生成的完整链接，可通过 Tailnet 或自有 HTTPS 入口访问。远程收音要求可信 HTTPS；不要直接公开本机端口，也不要仅为收音问题关闭浏览器安全设置。

### 在页面分享给局域网设备

WebUI 右上角“设置”齿轮中的“分享”按钮会自动生成二维码，也可复制链接或保存二维码图片。悬浮模式也可通过右上角设置打开分享。邀请 5 分钟有效、仅能配对一次；每个接收者使用独立设备授权和会话 owner，不复用主人的长期连接密钥。模型费用仍由电脑配置的账号承担。

首次使用的安卓设备需按指引安装局域网 CA 证书。已安装证书可勾选“直接进入 HTTPS 对话”。证书安装指引通过 HTTP 提供，只适用于可信局域网；对话始终通过 HTTPS/WSS 传输。二维码在服务器本地生成，不调用外部二维码服务。

“分享授权”列表区分待扫码和已配对，点击“撤销”可使未使用的邀请失效，或立即撤销已配对设备并关闭其连接。已配对授权不会随邀请的 5 分钟期限自动过期，撤销前持续有效。已配对设备的管理记录在 Gateway 重启后保留；未使用的邀请在重启后失效。接收者不能继续创建分享。

部署时设置 `QWEN_AUDIO_GATEWAY_SHARE_ORIGIN` 为手机可访问的 HTTPS Origin，例如 `https://192.168.1.10:8443`。使用本项目局域网分享桥时，另设 `QWEN_AUDIO_GATEWAY_SHARE_SETUP_ORIGIN=http://192.168.1.10:3080`，以便二维码打开首次证书安装指引。正式可信 HTTPS 部署可不设安装指引 Origin，直接分享 HTTPS 配对页。只监听 localhost 且没有 HTTPS 分享地址时不会生成分享。

### 简洁语音界面

主画面只保留左上连接状态灯、右上设置齿轮、中央云朵呼吸球和底部输入框。状态灯：红色为异常，绿色为模型已连接，灰色为断开或正在建立连接；悬停或打开设置可查看状态详情。模型信息、开始/断开连接、麦克风、分享、新会话、资料库、悬浮模式与视频入口均位于设置中。

点击中央球可开始语音并请求麦克风权限；收音时再次点击暂停收音，回复时点击可打断。对话出现消息后，球会缩小以保留聊天空间。配置空闲超时后，页面沿用服务端自动断开的机制。新云朵外观支持系统“减少动态效果”偏好；旧版内置 Web 外观首次升级时会切换为云朵，可在设置中重新选择原皮肤。

云朵动画可在右上设置中选择“跟随系统”“始终播放”或“关闭动画”，选择保存在当前浏览器。“跟随系统”会尊重浏览器的减少动态效果偏好；若希望为本页面启用动画，选择“始终播放”。隐藏页面时仍暂停绘制，重新显示后恢复。此选项只控制画面，不建立模型连接。

### 记忆与 Graphiti 组件

右上设置显示长期记忆是否跨设备共享、自动提取是否已开启及其消息门槛、间隔。记忆来源和各项限制见[记忆运行诊断](../operations/memory-runtime.zh.md)。Graphiti 的安装与统一启动方式见[组件说明](../../components/graphiti/README.zh.md)，当前阶段仅部署组件，现有记忆仍由 Markdown Provider 提供。
